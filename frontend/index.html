    HOW THE MATCH WORKS

    Red AI launches one attack per round. Blue AI runs it through its defenses in order:

    • Custom blocklist stops terms the app never allows.
    • Prompt Shields detects jailbreaks in the user prompt.
    • Prompt Shields (documents) detects instructions hidden in pasted text.
    • Foundry content filter blocks harmful content.

    Each blocked attack costs Red AI health. Each attack that gets through costs Blue AI health. The server decides the winner from the remaining health.
